# Hash Table Implementation

A custom Hash Table data structure built in Python. Features ASCII-based hashing function and nested dictionary mapping to manage and resolve key collisions gracefully. Built for the **freeCodeCamp Scientific Computing with Python** certification.

## 🛠️ Features

* **Custom Hashing Algorithm:** Computes hash keys based on the sum of ASCII character values (`ord`).
* **Collision Handling:** Uses nested dictionaries within hash buckets to safely handle hash collisions without losing data.
* **Core CRUD Operations:**
  * `add(key, value)`: Inserts or updates key-value pairs.
  * `lookup(key)`: Retrieves stored values by key.
  * `remove(key)`: Deletes targeted key-value pairs safely.

## 💻 Tech Stack

* **Language:** Python 3 (Data Structures & Custom Algorithms)
